# Go Backend Guidelines

Публичный репозиторий инженерных правил для backend-стека Go + DDD + PostgreSQL + goose + OpenAPI/AsyncAPI + gRPC + Kubernetes.

## Назначение

Этот репозиторий содержит правила проектирования и разработки Go-сервисов:

- структура сервиса;
- транспортные контракты;
- обработка ошибок;
- наблюдаемость;
- интеграции с инфраструктурой;
- правила библиотек и генерации кода.

## Использование

Репозиторий можно использовать:

- как внешний пакет backend-правил;
- как базовый набор документов для локальной проектной копии, например в `docs/design-guidelines/go/**` или аналогичном каталоге проекта;
- как основу для проектного overlay, где конкретный проект фиксирует свои auth/provider/release/naming conventions.

Стек этого пакета уже, чем просто «Go backend»: здесь зафиксированы подходы именно для сочетания Go + DDD + PostgreSQL + goose + OpenAPI/AsyncAPI + gRPC + Kubernetes.
