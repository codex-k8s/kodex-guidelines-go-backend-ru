# kodex guidelines go

Публичный репозиторий инженерных правил для Go backend.

## Назначение

Этот репозиторий содержит правила проектирования и разработки Go-сервисов:

- структура сервиса;
- транспортные контракты;
- обработка ошибок;
- наблюдаемость;
- интеграции с инфраструктурой;
- правила библиотек и генерации кода.

## Использование

До внедрения штатного импорта руководящих пакетов основной репозиторий `github.com/codex-k8s/kodex` хранит локальную копию этих файлов в `docs/design-guidelines/go/**`.

Изменения в этом репозитории и локальной копии в `kodex` должны синхронизироваться в одном рабочем срезе.

## Связанные репозитории

- `github.com/codex-k8s/kodex` — основная платформа.
- `github.com/codex-k8s/kodex-guidelines-common-ru` — общие инженерные правила.
- `github.com/codex-k8s/kodex-guidelines-vue-ru` — правила для Vue и TypeScript frontend.
